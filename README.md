# insanKaynaklariYonetimSistemi
Kullanıcıların kendi şifrelerini belirleyebildiği ve yeni şifre oluşturabildiği şifre yönetimi yapısı üzerinde çalıştım. Kullanıcı rolleri oluşturularak her kullanıcının rolüne göre erişebileceği ekranların ve gerçekleştirebileceği işlemlerin sınırlandırılması hedeflendi. Ayrıca kullanıcı giriş ekranı ve sabit sol menüye, dinamik içerik alanına sahip ana sayfa arayüzü geliştirdim. Sql Server kısmında ise tüm tablolar eklendi ve çoğu veri girişi yapıldı.
